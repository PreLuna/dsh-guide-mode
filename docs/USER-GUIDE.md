# 使用指南

## 1. 开始一段指导

1. 在主会话先发一条消息，使父 agent 在线；
2. 打开右侧栏「开始」→「指导」；
3. 输入问题，按 Ctrl/Cmd+Enter 或发送；
4. 指导在原生 `subagentchat` 对话页运行。

指导继承父会话最后一个 completed turn 之前的上下文，后续追问共享同一段对话。关闭页签只隐藏页面，不结束会话；可从 sidebar 专区或任务页重新打开。

## 2. 指导与主会话

- 指导可使用写工具，和主会话一样受 DSH 权限规则约束；
- 指导可以与主会话 goal 并行；
- 信任的直属指导不阻塞父会话续轮；
- 普通工作、pending、closing、结算中或身份未知时仍等待；
- 指导之间、指导与普通工作之间没有跨会话文件锁，修改同一文件时需要人工协调。

## 3. 模型隔离

默认开启：

- 主会话模型 `list_agents` 看不到指导及其后代；
- 模型对指导分支的 `send_message` / `interrupt_agent` 被拒绝；
- 普通工作分支和指导向父级回报仍放行。

需要在配置中关闭时使用 `model.hideGuidance` / `model.blockControl`。关闭后模型可见/可控制指导，风险由使用者承担。

## 4. sidebar

官方 `dsh-better-sidebar` 的任务树/图/计数不显示指导及其分支。任务页底部有独立指导专区：

- 显示当前会话的指导；
- 分组显示同一根会话下的其他指导；
- 可打开、归档、取消归档；
- 专区使用独立滚动区，不改变原生任务组件。

指导不会自动弹出普通任务页；普通工作子代理保持原行为。

## 5. 归档

- **手动归档**：停止执行、保留历史、从专区隐藏；可取消归档并重新打开；
- **自动归档**：默认关闭。显式开启后按压力阈值扫描，只归档符合条件且 idle 的指导；
- 归档不会删除会话数据；原生 UI 可能仍允许打开或输入，用户已接受该边界。

## 6. 管理页

「插件 → 指导」：

### 安装与重启进度

显示当前执行任务的阶段、进度和结果。任务执行期间不要重复发起其他包操作。

### 远端发布来源

- 显示当前公开仓库；
- 「检查更新」获取最新 Release；
- 选择安装/升级/manager 升级；
- 「下载并准备」只下载和校验；
- 预览精确计划后确认执行；
- 自动停机、执行、重启并返回核对。

取消的任务可点「重试任务」。

### 开发 link 来源迁移

仅对 `link:` 安装有意义：

- 显示各包来源/版本；
- 可下载发布包并比较内容差异；
- 生成精确迁移计划；
- 确认后停机切换；
- 失败恢复原 link 或源码快照。

所有包已经是固定 `file:` 缓存时显示 `0 / 7`，属正常。

### 安装组件

用于缺失组件的首次安装；选择组件、预览依赖、确认执行并重启。已安装组件请使用升级区。

### 组件升级与包版本恢复

选择兼容版本升级；升级前备份旧包、旧 lock 和配置；成功后可从历史事务恢复旧版本。

### 卸载、修复与管理器升级

- 勾选组件 → 预览原版本修复；
- 勾选组件 → 预览卸载（preset 受保护，goal 恢复原生 driver）；
- manager 升级使用可信本地目录或远端来源；
- 页面下方提供外部恢复命令。

### 包缓存

检查七个自有包的固定缓存是否缺失/损坏。缺失时可按 Release 附件 SHA 重建；只写缓存，不改依赖。

### 硬中断恢复

仅在检测到未完成事务时出现：

- 显示中断类型、事务 id、可恢复动作；
- 不给自动删除按钮；
- 停止目标 DSH 后，按页面给出的 helper/action/id 执行外部恢复。

## 7. 常见状态

| 状态 | 含义 |
|---|---|
| `ready` / `running` | 组件可用 |
| `ready-unverified` | 版本/产物未完整核对，功能可能可用 |
| `degraded` | 部分能力降级 |
| `unsupported` | 宿主或组件版本不在支持范围 |
| `missing` | 包未安装 |
| `disabled` | 用户禁用 |
| `verified-running` | 重启后运行核对通过 |
| `recovery-required` | 自动恢复失败，需要外部处理 |

## 8. 安全与边界

- 指导会实际读写工作区，使用前保存工作；
- 不要把凭据放到 prompt、URL 或页面路径；
- 公开源无需 token；私有源需要本机环境变量；
- 不承诺未知 DSH 版本兼容；
- 真实 Edge 的 link 迁移 UI、真实强杀/断电恢复仍在验证范围外。

见 [限制与兼容](LIMITS.md)。
